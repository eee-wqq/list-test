# List-test

A small to-do list made with HTML, CSS, and plain JavaScript.

## About
This project is a simple practice app focused on working with the DOM and basic user interaction.  
You can add tasks to a list and mark them as completed by clicking on them.

## Features
- Add tasks
- Mark tasks as completed
- Simple and clean layout
- No libraries or frameworks

## Built with
- HTML
- CSS
- JavaScript

## How to run
1. Clone or download the repository
2. Open `test.html` in your browser
3. Use the input to add tasks
